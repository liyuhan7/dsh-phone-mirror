# iPhone / iPad 连接与使用

插件通过 CoreDevice `DisplayService` 获取 iPhone / iPad 实时画面与声音，通过隧道 HID 完成触控、滚轮与键盘反控。手机端无需越狱，也无需安装任何 App。

## 传输与渲染链路

- **媒体与控制直连本地 sidecar**：视频（`/stream.bin`）、音频（`/audio.bin`）、触控/滚轮（`/touch`、`/key`）及关键帧请求（`/pli`）均由前端直接访问本地 Python sidecar，不经过 DSH 宿主事件循环，避免被主对话渲染阻塞。
- **浏览器媒体管线渲染**：WebCodecs 解码后的视频帧优先通过 `VideoTrackGenerator` 送入 `<video>` 呈现，配 4 帧队列与 16 ms 节拍输出；不支持该接口时自动回退到画布绘制。
- **低开销隧道与代理隔离**：sidecar 在入站方向对音视频 UDP 包旁路纯 Python 用户态协议栈（`pmd-pytcp`），只保留控制面 TCP 与出站 RTCP 走协议栈；同时自动清除系统代理环境变量，本机开启代理软件不会干扰本地投屏。

## 前提条件

| 项目 | 要求 |
| --- | --- |
| iPhone / iPad | **iOS 27 及以上**（更早版本没有 CoreDevice 实时画面流） |
| 电脑系统 | Windows 为主要验证平台；macOS / Linux 需本机 `usbmuxd` 可用 |
| Apple 驱动服务 | Windows 需安装 [Apple Devices](https://apps.microsoft.com/detail/9np83lwlpz9k) 或 iTunes；未安装时设备列表显示「驱动未就绪」 |
| 手机设置 | 打开「设置 → 隐私与安全性 → 开发者模式」，按提示重启确认 |
| iOS 运行时 | 随 npm 平台包安装（嵌入式 Python + `pymobiledevice3` + `PyAV`）；缺失时首次连接自动从 Release 下载（约 100 MB 压缩包），均不可用才回退到本机 Python 3.11+ |
| 磁盘空间 | 运行时解压后约 250 MB，位于 DSH 数据目录 |
| 无线网络 | iPhone 与电脑处于同一局域网且未被 AP 客户端隔离 |

运行时查找顺序：`DSH_PHONE_MIRROR_IOS_PYTHON` → 插件内 `tools/ios-runtime/<平台>` → npm 平台包 → 已缓存的 `~/.dsh/phone-mirror-ios-runtime/<版本>` → 按 `bridge/runtime-manifest.json` 从 Release 下载；全部不可用时回退到本机 Python 3.11+ 在 `~/.dsh/phone-mirror-ios-venv` 现场安装依赖。

## USB 连接

1. 用数据线连接 iPhone 与电脑，解锁手机，在「信任此电脑」弹窗点信任并输入锁屏密码。
2. 在 DSH 右侧栏点「+」添加「手机」页签，顶部平台切到 **iOS**。
3. 列表出现 `iPhone` 后点「连接」。首次连接会自动准备运行时并挂载开发者镜像（DDI），全程保持手机亮屏解锁，最长约 1 分钟。
4. 画面出现后，标题栏显示 `设备名 · 分辨率 · 实时帧率`（例如 `iPhone · 1290×2796 · 60fps`）。

常见连接提示：

| 提示 | 处理方式 |
| --- | --- |
| 请先解锁 iPhone，再点击连接 | 点亮并解锁手机后重试 |
| 尚未信任此电脑 | 解锁手机，在弹窗点信任并输入锁屏密码 |
| iPhone 尚未开启开发者模式 | 打开「设置 → 隐私与安全性 → 开发者模式」，重启确认 |
| 需要 iOS 27 及以上版本 | 系统版本过低，不支持 CoreDevice 实时画面流 |

设备列表中 `iPhone` 表示 USB 连接，`iPhone (Wi-Fi)` 表示已配对的无线设备，后方标明「在线」或「离线」。

## 画面与触控

- 点按、长按、拖拽与鼠标滚轮直接操作手机；iOS 仅响应鼠标左键。
- 画面按 contain 比例铺满面板；点「全屏 / 退出全屏」切换整窗铺满。
- 画面发黑、花屏或短暂卡住时，点「重建画面」丢弃解码器并向 sidecar 直发 `/pli` 请求新关键帧；链路丢包定格时服务端也会自动补发关键帧请求。
- 面板上的画质档位（流畅 / 标准 / 高清）仅对安卓生效，iOS 按原生分辨率出流。

## 键盘与输入法

点击画面即接管键盘，点击 DSH 聊天框或其他区域自动释放：

- **中文输入**：把电脑输入法切到英文后直接敲拼音，由手机输入法组字并在手机屏幕显示候选条，用数字、空格或回车选字上屏（手机需切换到简体拼音等中文键盘）。
- **英文与符号**：按外接键盘逐键转发，手机软键盘不会弹出。
- **快捷键**：`Esc` 转发给手机；`Ctrl+空格` 触发语言切换。
- **归还软键盘**：拿起或改变手机朝向时自动注销虚拟键盘、交还手机软键盘，点回画面即可重新接管。

## 声音

iPhone 声音采用 AAC-ELD 48 kHz 立体声转发，经本地 sidecar 的 `/audio.bin` 直连浏览器 AudioWorklet 播放（直连不可用时按需退回宿主中转）。

- 喇叭按钮控制静音与开启；若本机缺少 AAC-ELD 解码器，按钮置灰并提示，其余功能不受影响。
- 无线会话自动采用更高的缓冲水位（下限 `160 ms`、上限 `360 ms`、30 秒缓慢回退并记住本会话安全水位）以吸收 Wi-Fi 抖动；追帧时做 5 ms 交叉淡化，减少断音与噗啪声。

## 无线连接

### 方式一：USB 转无线（推荐）

1. 保持 USB 连接并解锁手机，点面板底部「转无线」。
2. 插件通过 USB 完成 RemotePairing 配对，学习手机当前 Wi-Fi 地址并验证无线隧道，提示验证通过后再拔线。
3. 拔掉数据线（当前 USB 会话会自动断开），在列表选中 `iPhone (Wi-Fi)` 点「连接」。

### 方式二：手填地址直连

点击「手填地址」，输入手机当前 IPv4 后点「连接」：

- 已配对设备直接按该 IP 建连，不依赖 mDNS。
- 未配对设备会在手机弹出「信任此电脑」，确认后自动完成首次无线配对并保存记录。
- 优先级：面板本次手填 IP ＞ 插件配置 `iosWirelessHost` ＞ USB 连接期间自动学习的地址。

### 无线要点与网络建议

- **自动重连与断开**：无线掉线会在 90 秒内自动重连；右上角「断开」仅停止当前投屏，底部「断开连接」会停止投屏并将无线条目从列表移除（保留配对记录）。
- **地址学习**：USB 连接稳定后插件会自动从手机出站流量学习其 Wi-Fi 或个人热点地址，抓不到时再按配对记录匹配 mDNS 兜底。
- **流畅度建议**：受 iOS 18.2+ CoreDevice 协议限制，无线投屏必须在单条 TLS TCP 隧道内复用视频、音频与控制流。在存在 Proxy ARP / AC 集中转发或高干扰的校园网、企业网中，画面大跨度跳转与声音容易出现抖动；追求接近 USB 的 60 fps 流畅体验时，建议使用 **5 GHz 手机个人热点 / 电脑移动热点** 或 **USB 数据线**。

## 故障排查

**设备列表显示「驱动未就绪」**
Windows 未安装 Apple Devices / iTunes，或 `Apple Mobile Device Service` 未启动。安装并启动服务后重新打开页签。

**列表里没有 iPhone**
确认手机已解锁并信任本电脑；USB 连接后重新打开页签刷新。若设备管理器中该接口被其他驱动占用，切回 Apple USB 驱动。

**长时间停在「正在连接…」**
首次连接可能正在下载约 100 MB 运行时（已安装 npm 平台包时不下载），完成后缓存在 `~/.dsh/phone-mirror-ios-runtime/1`。若 GitHub 下载受阻，可按顺序尝试：
1. 手动下载 Release 中的 `dsh-phone-mirror-ios-runtime-win32-x64.zip`，解压到 `%USERPROFILE%\.dsh\phone-mirror-ios-runtime\1\`，确认存在 `python\python.exe`。
2. 已有可用环境时，通过环境变量 `DSH_PHONE_MIRROR_IOS_PYTHON` 指向其 `python.exe`。
3. 安装本机 Python 3.11+ 后重试，插件将在 `~/.dsh/phone-mirror-ios-venv` 自动安装依赖。

若运行时已就绪仍卡住，多为开发者镜像挂载未完成，保持手机亮屏解锁后重试。

**插着线好好的，一拔线就断**
USB 在位时拔线会主动结束当前会话。请按「转无线 → 验证通过 → 拔线 → 选 `iPhone (Wi-Fi)` 连接」的顺序切换。

**无线连不上，提示未收到 RemotePairing 广播**
多为网络屏蔽组播或手机 IP 已变更。插回 USB 连一次刷新地址，或直接使用「手填地址」/ 配置 `iosWirelessHost`。若路由器开启了客户端隔离，只能换同一台无隔离路由器、改用个人热点或 USB。

**校园网无线下切页卡顿或声音偶发断续**
校园网常对无线客户端做 Proxy ARP 网关绕行，空口双跳叠加单 TCP 队头阻塞会放大抖动。建议优先改用 5 GHz 热点直连或 USB；继续使用校园网时，可在 Windows 设备管理器关闭无线网卡省电模式并调低漫游主动性。

**开启系统代理后无法投屏或触控失效**
插件已为 sidecar 与本地直连自动隔离代理；如仍异常，请检查代理软件的 TUN / 虚拟网卡模式是否接管了 `127.0.0.1` 回环流量或手机局域网网段，并将局域网网段加入直连白名单。

**没有声音或画面全黑**
喇叭置灰表示缺少 AAC-ELD 解码器；按钮正常但无声时检查电脑与手机音量及 App 录音捕获限制。画面全黑先点「重建画面」，确认手机未锁屏后重试。

## 维护者：构建 iOS 运行时

npm 平台包与 GitHub Release 共用同一构建产物：

```bash
npm run build:ios-runtime -- --python C:/Python311/python.exe --force
```

脚本会拉取嵌入式 Python、安装 `bridge/requirements.txt` 依赖、清理缓存并做冒烟测试，输出：

- `dist/ios-runtime/dsh-phone-mirror-ios-runtime-win32-x64/`（可直接 `npm publish`）
- 同名 zip 压缩包（用于 `ios-runtime-v1` Release）
- 更新后的 `bridge/runtime-manifest.json`（下载地址与 sha256）

也可在 GitHub Actions 手动运行 **iOS runtime** 工作流生成上述产物。发布时需先发布运行时平台包与 Release，再发布主包；变更 Python 版本或依赖时递增 `runtimeVersion` 以避免命中旧缓存。
