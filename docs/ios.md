# iPhone / iPad 连接与使用

插件通过 CoreDevice `DisplayService` 取 iPhone 画面，走隧道 HID 反控。iPhone 不需要越狱，也不需要在手机上安装任何 App；电脑侧使用 Apple 自带的驱动服务与一个本地 Python 子进程。

## 前提条件

| 项目 | 要求 |
| --- | --- |
| iPhone / iPad | **iOS 27 及以上**（更早的系统没有 CoreDevice 实时画面流） |
| 电脑系统 | Windows 为主要验证平台；macOS / Linux 需要本机 usbmuxd 可用 |
| Apple 驱动服务 | Windows 安装 [Apple Devices](https://apps.microsoft.com/detail/9np83lwlpz9k) 或 iTunes；未安装时设备列表显示「驱动未就绪」 |
| 手机设置 | 打开「设置 → 隐私与安全性 → 开发者模式」，按提示重启并确认 |
| iOS 运行时 | 随 npm 平台包安装（可移植 Python + `pymobiledevice3` + `PyAV`）；平台包缺失时首次连接自动下载约 100 MB（压缩包），再失败才需要本机 Python 3.11+ |
| 磁盘 | 运行时解压后约 250 MB，位于 DSH 数据目录 |
| 网络 | 无线投屏要求 iPhone 与电脑在同一局域网，且 AP 未做客户端隔离 |

运行时按优先级查找：`DSH_PHONE_MIRROR_IOS_PYTHON` 指定的 python → 插件内 `tools/ios-runtime/<平台>` → npm 平台包 → 已下载的 `~/.dsh/phone-mirror-ios-runtime/<版本>` → 按 `bridge/runtime-manifest.json` 从 Release 下载。只有全部不可用时，才回退到本机 Python 3.11+ 创建 `~/.dsh/phone-mirror-ios-venv` 并安装依赖。

## USB 连接

1. 用数据线连接 iPhone 与电脑，解锁手机，弹窗点「信任」并输入锁屏密码。
2. 打开 DSH 右侧栏的「+」，添加「手机」页签，把顶部的平台下拉切到 **iOS**。
3. 设备列表出现 `iPhone` 后点「连接」。首次连接若运行时尚未就绪会先自动下载（约 100 MB，仅一次），随后挂载开发者镜像（DDI），全程保持手机解锁，最长约 1 分钟。
4. 画面出现后，标题行显示 `iPhone · 1179×2556 · 30fps`（设备名 · 分辨率 · 实时帧率）。

连接过程中的提示都来自手机侧状态，按提示处理即可：

| 提示 | 处理 |
| --- | --- |
| 请先解锁 iPhone，再点击连接 | 点亮并解锁手机后重试 |
| 尚未信任此电脑 | 解锁手机，在「信任此电脑」弹窗点信任并输入密码 |
| iPhone 尚未开启开发者模式 | 打开「设置 → 隐私与安全性 → 开发者模式」，重启后确认 |
| 需要 iOS 27 及以上版本 | 手机系统版本过低，无法投屏 |

设备列表里的 `iPhone` 是 USB 连接，`iPhone (Wi-Fi)` 是已配对的无线设备，后面会标「在线」或「离线」。

## 画面与触控

- 点按、长按、拖拽直接操作手机；鼠标滚轮对应手机的滚动手势。
- iOS 只响应鼠标左键，右键与其他指针键不会下发。
- 画面按 contain 比例铺满面板，左右或上下留黑边；点「全屏」铺满整个窗口，点「退出全屏」返回。
- 画面发黑、发花或卡住时点「重建画面」：丢掉解码器重新拉流，由手机重发关键帧。
- 画质档位（流畅 / 标准 / 高清）只对安卓生效；iOS 按设备原生分辨率出流，切换档位不会改变 iPhone 画面尺寸。

## 键盘与输入法

点一下画面即接管键盘，之后直接用电脑键盘打字；点 DSH 的聊天框、工具栏等其它输入位置会把键盘还给 DSH。

- 拼音：把电脑输入法切到英文后直接敲拼音，字母发到 iPhone，由手机的输入法组字，候选条显示在手机屏幕上，用数字、空格或回车选字上屏。iPhone 的键盘需为简体拼音等中文输入法。
- 英文、数字与符号逐键转发，等同于手机连了一把外接键盘，手机软键盘不会弹出。
- `Esc` 转发给手机，用于收起输入法或取消当前操作。
- `Ctrl+空格` 按下手机的语言切换键，相当于 Caps Lock 切中英。
- 改变手机朝向会交还手机软键盘，此时点回画面可重新接管。

## 声音

iPhone 声音按 AAC-ELD 48 kHz 立体声转发，喇叭按钮控制开关。如果本机 FFmpeg 缺少 AAC-ELD 解码器，连接时不会订阅音频，喇叭按钮置灰并提示「当前环境缺少 AAC-ELD 解码器」，其余功能不受影响。

## 无线连接

无线连接通常先走一次 USB：配对记录与手机 Wi-Fi 地址都在这一步生成。换成手机开个人热点、电脑连热点也可以；或直接「手填地址」连一台没配对过的设备（见下）。

1. 保持 USB 连接并解锁手机，点面板底部的「转无线」。
2. 插件通过 USB 完成 RemotePairing 配对，读取手机当前的 Wi-Fi 地址并完整验证无线隧道，验证通过才提示可以拔线。
3. 拔掉数据线。当前 USB 会话会断开，这是正常现象。
4. 设备列表里选中 `iPhone (Wi-Fi)`，点「连接」。地址已经学到，直接按 IP 建连，不依赖 mDNS。
5. 无线会话掉线后，插件会在 90 秒内自动重开；超过窗口需要手动点「连接」。

要点：

- **地址学习**：插件在 USB 连接期间抓取手机自身出站流量的源地址（个人热点走 `bridge`/`ap` 接口，蜂窝流量与转发的服务器流量都会被排除），抓不到时再按配对记录匹配 mDNS 广播兜底。无线连接按学到的地址直连。
- **手填地址**：点「手填地址」输入手机 IPv4 直连。设备从未配对时，手机会弹「信任此电脑」，确认后自动建立配对并连接；列表里没有 iPhone 也能用。
- **IP 变化**：手机换了网络或 IP 后，地址缓存只保留最新学到的地址，插回 USB 连一次即可刷新；不想插线就手填覆盖。
- **断开连接**：停止无线投屏并把该设备从列表移除，配对保留。之后插 USB 点一次「转无线」即可恢复。
- **离线标记**：列表里的 `iPhone (Wi-Fi) · 离线` 按真实 TCP 探测结果判断；面板会提示插 USB 刷新地址，或检查手机是否在同一网络。
- **AP 隔离**：如果路由禁止客户端互访，无线连接会一直超时，只能换到同一台路由器下或改用 USB。

## 故障排查

**设备列表显示「驱动未就绪」**

Windows 上没有安装 Apple Devices 或 iTunes，或 Apple Mobile Device Service 没有运行。安装后确认服务已启动，再重新打开页签。

**列表里没有 iPhone**

先确认手机已解锁并信任本电脑；USB 连接后重新添加页签可刷新列表。设备管理器里若该接口被厂商驱动占用，换成 Apple 的 USB 驱动。

**点「连接」后长时间停在「正在连接…」**

首次连接可能需要下载约 100 MB 运行时（npm 平台包已安装时不会下载），完成后缓存在 `~/.dsh/phone-mirror-ios-runtime/1`，之后不再下载。下载走 GitHub，确认网络能访问。

下载失败时按顺序尝试：

1. 手动下载 Release 里的 `dsh-phone-mirror-ios-runtime-win32-x64.zip`，解压到 `%USERPROFILE%\.dsh\phone-mirror-ios-runtime\1\`，确认 `python\python.exe` 存在
2. 本机已有可用环境时，用 `DSH_PHONE_MIRROR_IOS_PYTHON` 指向它的 `python.exe`
3. 安装 Python 3.11+ 后重试，插件会在 `~/.dsh/phone-mirror-ios-venv` 现场安装依赖

下载完成仍然卡住，多半是开发者镜像未挂载完成，保持手机解锁并重试一次。

**插着线好好的，一拔线就断**

USB 在位时拔线会结束当前会话，包括已经切到无线的会话。无线投屏请按「转无线 → 拔线 → 连接」的顺序操作。

**无线连不上，提示没有收到 RemotePairing 广播**

说明地址还没学到或已经失效。插 USB 连一次刷新地址；仍然不行就在配置里手填 `iosWirelessHost`。

**没有声音**

先看喇叭按钮：置灰表示本机缺少 AAC-ELD 解码器，无法转发 iPhone 声音。按钮可用但没声音，检查电脑音量与手机音量，以及当前 App 是否允许被捕获。

**画面全黑**

先点「重建画面」。仍然全黑时断开重连，并确认手机屏幕本身是亮的；锁屏状态下画面就是黑的。

## 维护者：构建 iOS 运行时

运行时有 npm 平台包与 GitHub Release 两条分发路径，二者由同一个构建产物生成：

```bash
npm run build:ios-runtime -- --python C:/Python311/python.exe --force
```

脚本会下载嵌入式 Python、安装 `bridge/requirements.txt` 的依赖、清理缓存并冒烟测试。构建机需要 Python 3.11（用 `--python` 指定）和一次联网，然后：

- 生成 `dist/ios-runtime/dsh-phone-mirror-ios-runtime-win32-x64/`，可直接 `npm publish` 成平台包
- 生成同名 zip，用于 `ios-runtime-v1` Release，供没有平台包的安装下载
- 更新 `bridge/runtime-manifest.json` 的下载地址与 sha256

没有本地构建环境时，可以在 GitHub Actions 手动运行 **iOS runtime** 工作流（输入运行时版本），产物里包含 zip、npm 平台包目录与更新后的清单。

发布顺序：先发运行时平台包与 Release，再发主包；否则安装时可选依赖还解析不到。改了 Python 版本或依赖后重建运行时，并把 `runtimeVersion` 加一，旧缓存不会被误用。
